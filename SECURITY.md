# Security Policy

This repository contains documentation, configuration examples, and prompt examples for the QR Planet QR Code MCP Server. It does not contain server source code.

## Reporting a vulnerability

- **Issues with the QR Planet MCP server itself** (the hosted service at `api.qrplanet.com`) or your QR Planet account: contact QR Planet support via [qrplanet.com/contact](https://qrplanet.com/contact), not this repo's issue tracker.
- **Issues with this repo's docs or examples** (e.g. an example that encourages an insecure pattern, a leaked-looking credential, a broken link to a security-relevant page): open a GitHub issue on this repository, or contact us via [qrplanet.com/contact](https://qrplanet.com/contact).

Please do not include real API keys, tokens, or account identifiers in issue reports or pull requests.

## Handling API keys in examples

All API keys, client IDs, and secrets shown in this repository's docs and `examples/` files are placeholders (e.g. `YOUR_QR_PLANET_API_KEY`, `secret:YOUR_DOMAIN:YOUR_KEY_ID:YOUR_SECRET`). If you find a real credential committed anywhere in this repo's history, report it immediately via email above so it can be revoked.
